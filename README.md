# Потапенко: побег

Браузерная 3D-игра с видом сверху. В лобби есть коллекция из 18 бойцов, кейсы, способности и улучшения. Играй в одиночных уровнях, аркаде на выживание или рейтинговой онлайн-дуэли.

## Режимы

- **Уровни** — собирай шумилики, избегай Потапенко и открывай следующие этапы.
- **Аркада** — продержись минуту; монстр постепенно ускоряется.
- **ММР · Дуэль** — поиск второго игрока по аккаунту. Роли преследователя и беглеца выбираются случайно. Преследователь должен коснуться соперника, беглецу нужно выжить 60 секунд. Победа даёт 25 ММР, поражение снимает 15. В матче показываются выбранные бойцы обоих игроков.

Для дуэли каждый игрок должен открыть игру на одном и том же опубликованном сайте и войти в аккаунт. Локальные аккаунты и сохранения лежат в `.local/users.json`.

## Локальный запуск

```bash
pip install -r requirements.txt
python app.py
```

Открой `http://localhost:8000`. Учетная запись администратора: `owner`, пароль `0675097117`.

## Публикация с Gunicorn

Проект содержит WSGI-приложение Flask и `Procfile`. Хостинг должен установить пакеты из `requirements.txt`, затем запустить команду из Procfile:

```bash
gunicorn --workers 1 --threads 8 --bind 0.0.0.0:$PORT app:app
```

Для матчей используется память процесса, поэтому оставь один Gunicorn worker. Сохраняй `.local/users.json` на постоянном диске хостинга, иначе аккаунты и ММР пропадут при пересоздании контейнера. Это не глобальная сетка: матч найдётся, только когда оба игрока одновременно ищут игру на одном сервере.

Three.js загружается с CDN, поэтому для игры нужен интернет. На телефоне в настройках выбери устройство «Телефон»: интерфейс переключится на узкий вертикальный макет со стиком и кнопкой способности. На компьютере управление — WASD или стрелки, способность — E.
